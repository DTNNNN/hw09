## 一、程式用途與執行方式
本程式使用 Python 的 `tuple`、`list`、`set` 與 `dict` 容器，整理「桌遊體驗」與「電影欣賞」兩場活動的原始報名名單。程式會先清除多餘的半形空白、將英文姓名統一轉為小寫，並透過 `set` 去除單場重複報名，再利用集合運算（交集、聯集、雙向差集）比較兩場參加者，最後計算各自去重後的人數、總報名人次與應收費用。

## 三、個人回答

**問題一：測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 list，和再轉成 set，各自保留了什麼、失去了什麼？**
* **費用計算原因**：整理後的桌遊串列為 `['amy', 'ben', 'amy', 'cora']`，其中 `"amy"` 重複報名了兩次。依照活動規則，同一個人在同一場活動重複出現只算一位參加者、也只收一次費用，因此去除重複後實際只有 3 人，桌遊應收為 `3 × 120 = 360` 元。
* **`list` 與 `set` 的差異**：直接把字串拆成 `list`，**保留了**原始報名的先後順序以及重複出現的紀錄，但**失去了**元素唯一性；再轉成 `set` 之後，**保留了**不重複的唯一參加者名單，方便做交集、聯集、差集與算實際人數，但**失去了**原本的報名順序以及重複報名的次數資訊。

**問題二：測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。**
* **集合關係**：在測試三中，桌遊集合 $A = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$，電影集合 $B = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$。兩場名單完全相同，因此聯集 $A \cup B = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$，總不重複人數 $|A \cup B| = 3$ 人；交集 $A \cap B$ 同樣是這 3 人，表示這 3 個人兩場活動都有參加。
* **算式說明**：
  * **報名人次**：指兩場各自去重人數相加，即 $|A| + |B| = 3 + 3 = 6$ 人次。
  * **總應收金額**：兩場活動分別計費，桌遊應收 $3 \times 120 = 360$ 元，電影應收 $3 \times 80 = 240$ 元，合計 $360 + 240 = 600$ 元。
